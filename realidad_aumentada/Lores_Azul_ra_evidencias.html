Evidencias del bloque de Realidad Aumentada

En esta página iré incorporando las evidencias de las tareas del bloque de realidad aumentada.

Tarea 1 — Primera escena con marcador

En esta tarea hemos creado una sencilla experiencia de realidad aumentada. Hemos utilizado A-Frame para crear una escena 3D y AR.js para detectar una imagen específica (marcador), en este caso nuestro papel con la palabra Hiro, con la cámara de nuestro móvil. Al enfocar el marcador, aparece un objeto 3D sobre el papel, en nuestra experiencia aparece un cubo rojo. Hemos hecho dos archivos HTML: uno para poder hacer la experiencia, donde se muestra el marcador y el objeto 3D, y otro para las evidencias, en la que hemos adjuntado las imágenes de las pruebas. Para terminar, hemos subido todo a GitHub y lo hemos añadido a nuestra página web.

Tarea 2 - Segunda escena con marcador y nuestro propio objeto 3D

En esta hemos utilizado una vez más A-Frame para crear una escena 3D y AR.js para detectar una imagen específica o marcador, el cual no cambiaremos respecto a la tarea anterior. Esta vez al enfocar el marcador en vez de verse un cubo rojo veremos un objeto creado por nosotros mismos, hecho previamente, en mi caso una torre. Hemos hecho dos archivos HTML: uno para crear nuestro objeto 3D y otro para poder hacer la experiencia, donde se muestra el marcador y el objeto que hemos creado. Para terminar hemos subido todo a Github y lo hemos añadido a nuestra página web. Las evidencias de la siguiente tarea se muestran seguidamente.
